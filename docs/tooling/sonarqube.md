# SonarQube Configuration

SonarQube is configured in its web UI: this configuration is not stored in any file of the
repository. This page describes how to redo it on a fresh SonarQube instance.

## 1. Admin password

1. Log in at `http://localhost:9000` with the default `admin` / `admin`.
2. SonarQube forces a password change: use a password generated by a password manager.
3. Check that the default credentials are refused:
   `curl -s -u admin:admin http://localhost:9000/api/authentication/validate` returns `{"valid":false}`.

## 2. Project

| Field | Value |
|-------|-------|
| Project display name | `Step by Step` |
| Project key | `step-by-step` |
| Main branch name | `main` |

The analysis itself is configured in the `pom.xml` (Maven scanner), not in a
`sonar-project.properties` file.

## 3. Quality Gate

`step-by-step-gate` is a copy of the built-in *Sonar way* gate, with one change: coverage on new
code must be at least **60%** (instead of 80%), as decided in the specification. It is assigned to
the `step-by-step` project.

## 4. Tokens

| Token | Type | Stored in | Used by |
|-------|------|-----------|---------|
| `jenkins-step-by-step` | Project Analysis Token (`step-by-step` only) | Jenkins credential `sonar-token` (Secret text) | the pipeline (story 013) |
| `scripts-tp` | User Token | password manager | `scripts/check-sonarqube.sh` |
